## 1. 包含什么

本目录只包含**本项目原创**的机械零件：

```
hardware/
├── cad/source/          # SolidWorks 原生零件（.SLDPRT）
├── cad/stl/             # 3D 打印文件（.STL）
├── drawings/            # 装配图/工程图（PDF/PNG）
├── BOM.csv              # 物料清单
└── assembly.md          # 装配说明
```

## 2. 不包含什么

以下文件**不在本仓库**：

- 轮趣科技 R1 底盘、C30D 主控板的 CAD/STEP/装配模型；
- 包含厂家底盘的整车总装 `完整车.SLDASM`、爆炸图 `爆炸图.SLDASM`；
- 含厂家模型的装配工程图 `装配工程图.SLDDRW/.DWG`；
- 电池、球、轴承等通用件/采购件模型；
- 厂家的原理图、手册、示例工程。

原因：这些资产的再分发权利不属于本项目。需要时请从厂家获取，或使用简化的
占位模型表达安装接口。

## 3. 文件格式说明

| 格式 | 用途 | 说明 |
|---|---|---|
| `.SLDPRT` | 原生 CAD | 可修改尺寸、特征、配合；SolidWorks 2021 或更新版本打开 |
| `.STL` | 3D 打印 | 单位 mm；打印前在切片软件中检查法向与壁厚 |
| `.STEP` | 跨 CAD 交换 | **待补**：发布前从 SLDPRT 导出，建议放在 `cad/step/` |
| `.SLDASM` | 装配 | 本地保留；含厂家模型的装配不公开 |
| `.SLDDRW` / `.DWG` | 工程图 | 本地保留；关键零件可导出 PDF 后公开 |

> 如果你使用 Fusion 360、FreeCAD、Onshape 等工具，优先使用 STEP；
> 目前 STEP 尚未导出，是 v0.1.0 的已知缺口。

## 4. 制造建议

1. **打印方向**：叶片与收拢爪的层纹方向会影响抗冲击性；尽量让层纹沿主要受力方向。
2. **壁厚与填充**：后箱建议 3–4 层壁、20–30% 填充；叶片与爪建议更高填充或尼龙材料。
3. **公差**：3D 打印孔位常偏小 0.1–0.3 mm；M3 孔可先用 3.2 mm 钻头修整。
4. **轴承配合**：605ZZ（5×11×5）为自由端支承；盒盖用于轴向定位。若打印收缩导致
   轴承过紧/过松，可加热嵌入或使用少量胶固定。
5. **装配修正**：比赛样机出现前爪下端与支架干涉，现场采用“断开下连接处 + 铁丝绕孔固定”。
   建议在打印前用 SolidWorks 干涉检查，或把该处改为可调长圆孔。
6. **紧固件**：M3×6/7/8/9/10/12/25/30 螺钉与 M3 螺母，装配用量约 36 套；
   建议使用螺纹胶防松。

## 5. 装配与验证

详细步骤见 [assembly.md](assembly.md)。关键检查点：

- 叶片与前端壳体的径向/轴向间隙；
- 左右爪与地面的间隙（避免刮地）；
- 后箱入口与叶片拨送方向的对齐；
- 叶片轴同轴度与自由端轴承转动顺畅；
- 所有支架孔位与底盘安装孔匹配；
- 线束不进入叶片旋转包络。
