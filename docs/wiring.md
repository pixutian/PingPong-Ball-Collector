# Wiring · 电气接线

> 本文以 `firmware/original/yellow_motor.h` 和实际 PWM 配置为准。
> 项目报告中的“PC6 → AIN1”表述与代码不一致，接线前请用万用表确认 TB6612 引脚定义。

---

## 1. 系统框图

```
12V 锂电池 ──> C30D 电源输入
                 │
                 ├─ 板载 4 路底盘驱动 ──> M1–M4 ──> 4× MG310P20 电机
                 ├─ 编码器 E1–E4 <── 4× 霍尔编码器
                 ├─ USART2 (PD5/PD6) <──> JDY-33 蓝牙模块
                 ├─ I2C / OLED
                 ├─ ADC ← 电池分压
                 └─ PC6 (TIM8_CH1) ──> TB6612 PWMA
                                         │
                    3V3 ──> STBY / AIN1  │
                    GND ──> AIN2         │
                    5V  ──> VM           │
                                        AO1/AO2 ──> 5V 叶片电机
```

---

## 2. C30D ↔ TB6612 ↔ 叶片电机

| C30D / 电源 | TB6612 | 说明 |
|---|---|---|
| `PC6`（TIM8_CH1，AF3） | `PWMA` | 叶片 PWM 输入，约 16.8 kHz |
| `3V3` | `STBY` | 使能；高电平工作 |
| `3V3` | `AIN1` | 方向固定为正转 |
| `GND` | `AIN2` | 方向固定；与 AIN1 组成正转 |
| `GND` | `GND` | 必须共地 |
| `5V` | `VM` | 叶片电机电源；**不要接 12V** |
| — | `AO1` | 叶片电机一端 |
| — | `AO2` | 叶片电机另一端 |

> **重要**：TB6612 的 `VM` 是电机电源，`VCC` 是逻辑电源。不同模块丝印可能不同；
> 接线前确认模块上的 `VM`/`VCC` 标注。若模块只有 `VCC`，请按模块说明接 5V 逻辑，
> 电机电源单独供给。
>
> **不要**把底盘 12V 直接接到 5V 叶片电机或 TB6612 的 5V 逻辑端。

### 为什么是 PWMA 而不是 AIN1？

`yellow_motor.h` 把 `PC6` 配置为 `TIM8_CH1` 的 PWM 输出，代码通过
`TIM8->CCR1` 改变占空比。PWM 必须进入 TB6612 的 `PWMA` 才能调速；
`AIN1/AIN2` 只负责方向。因此：

- `PC6 → PWMA`
- `AIN1 = 3V3`，`AIN2 = GND` → 固定正转
- 如需反转，把 `AIN1/AIN2` 对调，或改用 GPIO 控制方向（当前代码未实现）。

## 3. 底盘电机与编码器

底盘电机和编码器按 WHEELTEC R1 小车底盘原厂标识连接：

| C30D | 电机/编码器 |
|---|---|
| `M1` | 左前（或按厂家定义） |
| `M2` | 右前 |
| `M3` | 左后 |
| `M4` | 右后 |
| `E1`–`E4` | 对应电机编码器 |

代码中的轮组定义：

- A/C 为左侧，B/D 为右侧；
- `EncoderB = -Read_Encoder(3)`、`EncoderD = -Read_Encoder(5)` 用于统一正向；
- 若更换电机/接线，先确认“前进时四轮目标转速同号、实际轮速同向”。

> 不同批次的 R1 可能改变 M1–M4 与物理轮位的对应关系。以实车前进测试为准，
> 必要时在代码中交换目标转速或调整电机线。

## 4. 蓝牙模块

| C30D | 蓝牙模块 | 说明 |
|---|---|---|
| `PD5`（USART2_TX） | `RXD` | 交叉连接 |
| `PD6`（USART2_RX） | `TXD` | 交叉连接 |
| `3V3` 或 `5V` | `VCC` | 按模块规格；JDY-33 通常 3.3–5 V |
| `GND` | `GND` | 共地 |

- 波特率：**9600 8N1**。
- 模块类型：JDY-33 兼容 SPP；厂家 BSP 会过滤 JDY-33 的 AT 反馈。
- 如果使用 HC-05/HC-06，协议可能兼容，但 AT 反馈过滤逻辑不同，需要实测。

---

## 5. 电源与电池

| 项目 | 说明 |
|---|---|
| 主电池 | 12 V 2550 mAh 锂电池（厂家配套） |
| C30D 供电 | 电池接入 C30D 电源输入；注意正负极 |
| 叶片电机 | 5 V，经 TB6612 由 C30D 5V 供电 |
| 逻辑 | C30D 3V3 供 TB6612 STBY/AIN1 |
| 共地 | 电池、C30D、TB6612、蓝牙模块必须共地 |

**上电顺序建议**：先接好所有地线 → 接 5V/3V3 逻辑 → 最后接电池。
**断电顺序**：先断电池 → 再拆其他线。

---

## 6. 上电前检查

1. 万用表二极管档/电阻档：5V 对地、12V 对地不应短路。
2. 确认 TB6612 的 VM 与叶片电机额定电压匹配（5V）。
3. 确认电池极性；反接可能瞬间损坏 C30D。
4. 确认所有插头锁紧，线束不进入叶片/车轮包络。
5. 架空车轮，先只上 C30D，确认 OLED 和蓝牙正常。
6. 再上 TB6612/叶片电机，先用 `T/U` 从低占空比开始。

---

## 7. 调试顺序

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 只上 C30D | OLED 亮，显示 0 转速、电压 |
| 2 | 蓝牙连接 | App 能连接，收发正常 |
| 3 | 发送 `A` | 四轮同向，车前进 |
| 4 | 发送 `E` | 四轮反向，车后退 |
| 5 | 发送 `C`/`G` | 原地右/左转 |
| 6 | 发送 `T` | 叶片占空比 +10%，电机转动 |
| 7 | 发送 `U` | 叶片占空比 −10% |
| 8 | 发送 `X`/`Y` | 速度挡位 ±20 |
| 9 | 断开蓝牙 | **当前版本不会自动停车**；立即手动断电 |
