## 2. 版本与兼容性矩阵

### 2.1 主控板

| 主控 | 兼容性 | 说明 |
|---|---|---|
| C30D V2.2 | ✅ 已验证 | 本项目目标板 |
| C30D V2.1 | ⚠️ 可能兼容 | 原理图/资源分配接近，但引脚与驱动可能不同，需逐项核对 |
| C30D V2.0 | ⚠️ 未验证 | 厂家基础例程版本不同，不能直接套用 |
| 其他 STM32F407 板 | ❌ 不保证 | 电机驱动、编码器、OLED、蓝牙接口都需重做 |

### 2.2 底盘

| 底盘 | 兼容性 | 说明 |
|---|---|---|
| R1 四驱（淘宝购置） | ✅ 已验证 | 实车 4× MG310P20，四轮差速 |
| R1 其他批次 / 其他轮趣底盘 | ⚠️ 未验证 | 电机、减速比、轮径可能不同 |
| 其他四驱底盘 | ⚠️ 需改代码 | 需重新确认 M1–M4、编码器符号、减速比、轮径 |

### 2.3 蓝牙模块

| 模块 | 兼容性 | 说明 |
|---|---|---|
| JDY-33 兼容 SPP | ✅ 已验证 | 厂家 BSP 含 JDY-33 AT 反馈过滤 |
| HC-05 / HC-06 | ⚠️ 可能兼容 | SPP 透传可用，但 AT 反馈过滤不同；需实测 |
| BLE 模块（非 SPP） | ❌ 不兼容 | 当前固件/自研 App 使用经典蓝牙 SPP |

### 2.4 手机 App

| App | 兼容性 | 说明 |
|---|---|---|
| 厂家蓝牙 App | ✅ 兼容对照 | 仅用于对照，不在本仓库；本项目开源的是自研 App |
| 自研 App V3.2 | ✅ 推荐用于本项目 | Android 6.0+；圆盘 + 7 档车速/叶片 + 遥测；无断线重连 |
| 其他串口 App | ⚠️ 需匹配 | 发送 ASCII `A`–`H`/`S`/`T`/`U`/`X`/`Y` 即可；不要自动追加回车；档位键间隔 ≥250 ms |

### 2.5 固件基线

| 基线 | 兼容性 | 说明 |
|---|---|---|
| `Fusion_OpenCar`（本仓库完整工程） | ✅ 本项目固件 | 不依赖厂家示例；`Driver/` 为 ST 标准库 |
| 其他厂家示例（FreeRTOS/雷达版） | ❌ 不直接兼容 | 任务结构、BSP、引脚不同 |
| 其他厂家示例工程 | ⚠️ 需移植 | 引脚、BSP、任务结构不同，不能直接套用 |

## 4. 未验证/不支持的场景

- **视觉识别、ROS 2、SLAM、自主导航**：当前固件没有这些功能，也没有预留接口。
- **>10 个球/更复杂场地**：没有系统测试数据；机构可能卡球或漏球。
- **斜坡/地毯/湿滑地面**：四轮差速与 PI 参数按平地整定，未验证。
- **长时间连续运行**：叶片电机与 TB6612 的温升未做长时间测试。
- **不同批次 R1/C30D**：厂家可能更改电机、编码器、接口定义；必须实测。

## 5. 兼容性检查清单

复现前请逐项确认：

- [ ] 底盘型号与电机铭牌（MG310P20？减速比 30？）
- [ ] 主控版本（C30D V2.2？STM32F407VET6？）
- [ ] 编码器线数（13 PPR？霍尔？）
- [ ] 电池电压（12 V？）
- [ ] 蓝牙模块（JDY-33 兼容？9600？）
- [ ] 叶片电机电压（5 V？不要接 12 V）
- [ ] TB6612 引脚定义（PWMA/AIN1/AIN2/STBY/VM）
- [ ] 手机系统版本与蓝牙权限
- [ ] 厂家 App 版本与协议

如果任何一项不同，请先降级到“只测试底盘”，再逐步接入收球机构。
