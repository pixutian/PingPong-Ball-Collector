# Troubleshooting · 常见问题

> 排查顺序：**电源 → 烧录 → 蓝牙 → 底盘 → 叶片 → 收球机构**。
> 每次只改一个变量，改完记录现象。

---

## 1. 上电与显示

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 上电无反应 | 电池没电/接反/保险断 | 万用表测电池电压；确认极性；检查 C30D 电源 |
| OLED 不亮 | OLED 未插好/I2C 地址不对/初始化顺序 | 重新插拔；确认 `OLED_Init()` 在 `main()` 中调用 |
| OLED 显示乱码 | 字库/坐标/刷新问题 | 用厂家原版例程对比；确认 `OLED_Refresh_Gram()` |
| 电压显示 0 | ADC 通道/分压比不对 | 确认 `Battery_Ch` 与 ×11 分压；测 ADC 引脚电压 |
| 电压显示跳动 | 电机干扰/采样时刻 | 在电机停止时校准；增加滤波 |

## 2. 烧录与编译

| 现象 | 可能原因 | 处理 |
|---|---|---|
| Keil 编译报错找不到 `yellow_motor.h` | 头文件未加入 Include Paths | 把 `USER/` 加入 Include Paths；确认文件名大小写 |
| 编译报错 `TIM8` 未定义 | 未包含 `stm32f4xx.h` 或宏开关 | `yellow_motor.h` 已包含 `stm32f4xx.h`；确认工程芯片为 F407 |
| ST-Link 连不上 | 驱动/接线/复位 | 检查 SWDIO/SWCLK/GND/3V3；按住复位再连接；换 USB 口 |
| 无线烧录失败 | 模块配置/串口占用 | 按厂家无线烧录说明；确认 BOOT0/复位时序 |
| 烧录成功但不运行 | 时钟/启动文件/中断向量 | 用厂家原版工程对比；确认 `system_stm32f4xx.c` 与晶振 |
| 程序跑飞/硬件错误 | 数组越界/中断优先级/栈 | 检查 `sprintf` 缓冲区；确认中断优先级分组；减小栈使用 |

> 本项目固件为独立工程（不依赖厂家示例）；如果连空工程都无法烧录，先解决工具链/驱动，不要改应用层。

## 3. 蓝牙与 App

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 手机搜不到模块 | 模块未供电/未进入配对模式 | 测 VCC/GND；按模块说明进入 AT/配对模式 |
| 能配对但连不上 | SPP 未建立/被其他设备占用 | 忘记设备后重配；关闭其他串口 App；重启模块 |
| 连上但无响应 | TX/RX 接反/波特率不对 | 交换 TX/RX；确认 9600 8N1 |
| 发送 `C` 无反应 | 厂家 BSP 过滤了 `C` | 删除 `bsp_bluetooth.c` 中的 `recv=='C'` 分支 |
| 发送文本后车乱动 | 任意字节映射为 `dirkey` | 只发送单字符指令；不要追加回车/空格 |
| 厂家 App 正常，自研 App 不行 | 自研 App 只支持部分指令/需要配对 | 先在系统蓝牙中配对；确认 UUID/SPP；看收发日志 |
| Android 12+ 连不上 | 缺少 `BLUETOOTH_CONNECT` 运行时权限 | 在系统设置中授予“附近设备”权限 |
| 蓝牙断开后车继续跑 | **没有通信超时** | 立即断电池；建议实现 500 ms 看门狗 |

## 4. 底盘运动

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 一上电就冲 | 电机线反接/`dirkey` 初值/编码器符号 | 架空车轮；检查 `SpeedSet` 与 `dirkey` 初值；确认电机线 |
| 前进变成后退 | 电机极性/代码符号 | 交换电机两根线，或改代码符号（只改一处） |
| 转向相反 | 左右轮定义/M1–M4 对应 | 交换左右目标或电机线；确认 A/C 左、B/D 右 |
| 直线跑偏 | 轮径/地面/编码器计数/PI | 测四轮实际转速；校准 `ENCODER_ACCURACY`；微调 PI |
| 一动就抖 | PI 参数过激/机械间隙 | 降低 Kp/Ki；检查轮子/联轴器/编码器固定 |
| 速度上不去 | 电池电压低/限幅/摩擦 | 测电池；确认 `SpeedSet` 上限 480；检查机械卡滞 |
| 原地转不动 | 转向缩放 1.5 过大/地面摩擦 | 降低 `TURN_SPEED_SCALE`；检查轮子是否卡住 |
| 编码器计数不变 | 编码器线/电源/定时器 | 检查 E1–E4；用手转轮看计数；确认 TIM2–TIM5 编码器模式 |

> `TURN_SPEED_SCALE` 当前为 1.5，转向目标转速高于直行。若实车转向过猛，
> 先降到 1.0 或 0.8 再试。

## 5. 叶片与 TB6612

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 叶片不转 | STBY 低/VM 无电/PWMA 无信号 | 测 STBY=3.3V、VM=5V、PC6 有 PWM |
| 叶片只转一下 | 占空比 0/电机堵转/电源限流 | 用 `T` 加到 50%；手动转叶片；测 5V 电流 |
| 叶片方向反 | AO1/AO2 接反 | 交换 AO1/AO2（断电操作） |
| 叶片转速不可调 | PC6 未配置为 TIM8_CH1/未调用初始化 | 确认 `YellowMotor_Init()` 在初始化后调用 |
| TB6612 发热 | 电机堵转/电压过高/散热差 | 立即断电；确认 VM=5V；检查卡滞；加散热 |
| 一开叶片就复位 | 5V 电源跌落/电池电量低 | 分开供电；加电容；换更大电流电源 |
| 叶片噪音大 | 动平衡/轴承/刮擦 | 检查叶片紧固、轴承、与壳体间隙 |

> **不要**把 12V 直接接到 5V 叶片电机或 TB6612 的 5V 逻辑端。

## 6. 收球机构

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 漏球 | 爪离地太高/入口太窄/车速太快 | 降低爪间隙到 5–10 mm；加宽入口；降速 |
| 卡球 | 叶片与爪之间有死区/过渡面不顺 | 加大过渡圆角；调整叶片相位；提高转速到 60–80% |
| 球进不去后箱 | 后箱入口高/叶片拨送方向不对 | 降低后箱；确认叶片旋转方向；检查后箱入口对齐 |
| 球从侧面弹出 | 爪弧度/间隙不对 | 调整左右爪对称性；加侧挡 |
| 叶片刮壳体 | 打印变形/同轴度/轴承 | 修整壳体；检查轴承/轴；加垫片 |
| 前爪断裂 | 层纹/材料/撞击 | 换 PA12/尼龙；增加壁厚；做可更换件 |
| 后箱变形 | 树脂收缩/壁厚不足 | 加厚/加筋；打印后校正；避免高温 |

> 比赛样机的现场修正（断开前爪下端 + 铁丝固定、拆除一侧电机做自由端）是**临时方案**，
> 不建议作为长期复现方案。

## 7. 电池与续航

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 续航很短 | 电池老化/叶片负载大/频繁转向 | 测容量；降低叶片占空比；减少原地转向 |
| 电压快速下降 | 电池内阻大/电芯不一致 | 换厂家电池；不要用劣质电芯 |
| 充电发热 | 充电器不匹配/过流 | 使用原厂充电器；不要无人看管充电 |
| 低压报警/突然停 | 保护板触发 | 立即停止；充电；检查是否堵转 |

## v0.2 新增排查

### APP 档位与车端不一致

1. 确认固件与 APP 都是 v0.2：底盘 7 档（100–700 r/min）、叶片 7 档（70%–100%，每档 5%）。
2. 连接后先按一次“停止”，再按一次“＋/－”让两端重新对齐。
3. 不要快速连点：固件对档位键有 200 ms 去抖；APP 已用 260 ms 队列，但第三方串口工具不会。
4. 若仍不一致，可加 `{D}` 回传补丁（`firmware/README.md` 5.1），APP 会自动对齐。

### APP 显示“本地估计”

未收到 `{D}` 帧时的正常状态。加固件补丁后会在收到帧时变绿显示“已与车端同步”。

### 叶片档位只有 70%–100%

v0.2 的档位是 7 档 × 5%，从 70% 到 100%。若需要 40%–100% 全范围，把
`AUX_GEAR_COUNT` 改为 13、`AUX_GEAR_CENTER` 改为 6，并同步修改 APP 的 `AUX_STEP/COUNT`。

### 编译 APP 时 d8 报 NullPointerException

build-tools 34 的 d8 与 JDK 21 不兼容，改用 build-tools 35.0.0 及以上。

### 安装 APK 提示签名不一致

仓库不含私钥；用你自己的 keystore 重签。若手机已装旧签名版本，先卸载。

## 结构相关（v0.2 样机实测）

### 前端打印件变形、孔位对不上

- 原因：大件打印翘曲、收缩，或支撑/摆放方向不合适。
- 临时处理：断开与支架干涉的局部，用铁丝穿过孔位绕紧固定（样机实物可见）。
- 改进：优化支撑与打印方向、加厚/加强筋、分件打印、孔位预留 0.3–0.5 mm 余量；装配前先试装。

### 导流爪与叶片之间卡球

- 原因：爪与叶片扫掠面之间存在空隙，球被挤入后卡住。
- 临时处理：左右导流爪加弯折铁丝隔断，阻断卡球位置。
- 改进：延长导流爪直杆段、缩小爪-叶片间隙、平滑导流面，必要时加柔性挡片。
