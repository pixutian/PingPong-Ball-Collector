# Vendor Hardware · 轮趣硬件依赖说明

> 本项目建立在轮趣科技（WHEELTEC）的成品硬件之上。这份文档说明**哪些是采购件、
> 哪些是原创件、哪些资料不能随项目开源**，方便复现者合法获取依赖。

---

## 0. 版本与自研边界（先看这里）

- 当前为**遥控版**；带摄像头的**自动收集版（YOLO / OpenCV）**在后续版本更新。
- **采购件只有底盘**：底盘 = 电机、车轮、车底板（淘宝购置的轮趣 R1 小车底盘）；**除底盘外的收球机构（三叶片、左右爪、前壳体、储球箱、支架等）均为自行设计**。
- **C30D 主控板同样是轮趣科技的产品**（STM32F407VET6），本项目在其上完成整车固件开发。
- 厂家资料（原理图、CAD、手册、示例工程、App）不随本仓库分发，请从轮趣官方获取。
- **所有控制代码（固件、App）均为团队自行编写**，未在厂家示例代码上二次开发；**蓝牙 App 为纯自研，不是厂家 App**。

## 2. 哪些是原创，哪些是采购

### 原创（本项目）

- 三叶片收球机构、左右收拢爪、后储球箱、前壳体；
- 前挡顶、单/双支架、拱顶、盒盖、叶片轴、地板；
- `yellow_motor.h` 叶片电机驱动；
- 应用层控制逻辑（八方向差速、四轮 PI、叶片 PWM、OLED 显示、状态帧）；
- 自研 Android App V3.2（纯自研，不是厂家 App）。

### 采购（轮趣科技）

- R1 底盘、C30D 主控板、MG310P20 电机、电池、蓝牙模块、OLED；
- 厂家的底盘结构、PCB 布局、原理图、示例工程、手册、App。

> 采购件的设计版权归轮趣科技。本项目**不**把厂家底盘/主控板称为“自主设计”，
> 也**不**在仓库中分发厂家的 CAD、原理图、手册或示例工程。

## 3. 为什么不把厂家资料一起开源

轮趣科技资料包中的《版权声明》明确写明：

> 未经本公司书面许可，任何单位及个人不得以任何方式或理由对本手册内的产品、
> 服务、信息、材料的任何部分进行复制、修改、抄录、传播、翻译成其他语言、
> 或与其它产品捆绑使用、销售。

因此，本项目的默认做法是：

1. **不复制**厂家手册、原理图、资源分配表、通信协议 PDF；
2. **不复制**厂家示例工程（`CORE/`、`FWLIB/`、`SYSTEM/`、`WHEELTEC_BSP/`）；
3. **不复制**厂家底盘/主控板 CAD（`C30D-V2.2_2026.04.20.stp/.SLDASM`）；
4. **不复制**厂家蓝牙 App 的安装包或截图用于再分发；
5. 在文档中只引用**型号、官方链接和必要的接口说明**。

如果轮趣科技书面同意，可以在仓库中加入：

- 基于 C30D 蓝牙示例修改的完整 Keil 工程；
- 含厂家底盘的装配文件（或简化占位模型）；
- 厂家 App 的官方下载链接/二维码；
- 厂家要求的署名与免责声明。

## 4. 复现者如何获取依赖

1. 通过轮趣科技淘宝店购买 R1 小车底盘与 C30D 主控板；
2. 向厂家客服索取对应版本的资料包（含示例工程、原理图、通信协议、App）；
3. 直接打开 [firmware/README.md](../firmware/README.md) 中的完整工程 `Fusion_OpenCar` 编译烧录（不依赖厂家示例）；
4. 按 [docs/wiring.md](wiring.md) 接线；
5. 按 [hardware/assembly.md](../hardware/assembly.md) 装配原创机构。

> 如果你使用的不是 R1/C30D，请先阅读 [docs/compatibility.md](compatibility.md)，
> 不要直接套用引脚和参数。

## 6. 需要向厂家确认的问题

如果你正在联系轮趣科技，建议一次问清：

1. **固件再分发**：是否允许公开“基于 C30D 蓝牙 App 示例修改”的完整 Keil 工程？
   还是只允许发布原创模块 + 修改说明？
2. **CAD 再分发**：是否允许公开含 C30D/底盘模型的装配文件？如果不允许，
   是否可以使用简化占位模型并标注接口尺寸？
3. **商标与型号**：是否允许在 README/视频中标注“基于 WHEELTEC R1 与 C30D”
   并链接官网？是否需要特定的署名格式？
4. **App 推荐**：是否允许把厂家蓝牙 App 作为推荐方案，并链接官方下载页？
5. **版本确认**：本项目使用的 C30D V2.2 / R1 / MG310P20 / JDY-33 组合
   是否仍在支持范围？是否有推荐的示例工程版本？
6. **免责声明**：厂家是否要求增加特定的安全/免责声明？
7. **技术支持**：如果复现者遇到硬件问题，推荐的售后/技术支持入口是什么？

> 在得到书面答复前，公开仓库只包含原创机械件、`yellow_motor.h` 和文档；
> 完整工程放在本地“待厂家确认”目录，不上传。
